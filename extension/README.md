# boring button — Manifest V3

распакованная офлайн-версия `boring button`. popup выдаёт локальную задачу на 10–120 секунд, запускает таймер и сохраняет активную сессию между открытиями.

## установка

1. открой `chrome://extensions` или `edge://extensions`.
2. включи **Developer mode**.
3. нажми **Load unpacked** и выбери папку `extension/`.
4. закрепи расширение на панели браузера.

в Firefox открой `about:debugging → This Firefox → Load Temporary Add-on` и выбери `manifest.json`.

## разрешения и данные

в manifest нет разрешений, host permissions и content scripts. popup работает только со своими файлами и `localStorage`: не читает вкладки, историю, cookies, содержимое страниц и не делает сетевых запросов.

локально хранятся свои задачи, минимальная статистика и активная сессия. счётчик текущего дня обновляется по местному времени устройства. **«изменить»** правит задачу на месте; **«удалить свои задачи»** и **«сбросить статистику»** очищают данные по отдельности.

## импорт и экспорт

JSON принимает массив задач или контейнер с полем `tasks`; CSV — заголовки `id,category,title,prompt,durationSec`. название и инструкция обязательны, длительность — целое число от 10 до 120 секунд. импорт ограничен 1 МБ и 200 пользовательскими задачами; дубликаты и повреждённые строки не добавляются.

## клавиатура

`Enter` запускает задачу или выдаёт ещё одну, `D` отмечает сделанное, `S`/`Escape` пропускает, `N` выдаёт ещё одну. внутри полей ввода горячие клавиши отключены. пауза и перезапуск доступны с клавиатуры и мышью.

## быстрая проверка

проверь popup без сети на ширинах 320–360 px: старт, пауза, продолжение, перезапуск, три действия, восстановление после закрытия popup, импорт JSON/CSV, повторный импорт и отсутствие горизонтального скролла.
