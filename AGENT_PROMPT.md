# промпт для агента: boring button

сделай офлайн-антискролл. пользователь нажимает одну кнопку и получает одну короткую задачу, наблюдение или мини-игру из локального набора. нужен статический сайт для GitHub Pages и расширение Manifest V3 с popup.

## сценарий

пользователь нажимает «дай задачу», получает действие на 10–120 секунд, а потом отмечает «сделано», «пропустить» или «ещё одну». локальный JSON содержит не меньше 30–50 задач в категориях движение, внимание, порядок, наблюдение и мини-игра. пользователь может добавить свои задачи и импортировать/экспортировать список. на устройстве сохраняется только минимальная статистика.

## ограничения

- не используй аккаунты, обязательный backend, API-ключи, сетевую базу, авторизацию или внешнюю AI-модель;
- файлы пользователя обрабатывай только в браузере;
- в расширении не добавляй host permissions, content scripts и доступ к вкладкам;
- если внешний URL не работает из-за CORS или лимитов, оставь полноценный локальный путь через JSON или CSV;
- сначала зафиксируй пользовательский сценарий и дизайн-систему, потом пиши код;
- проверь desktop/mobile, клавиатуру, focus-visible, reduced motion, пустые состояния и ошибки.

## визуальный голос

добрая муниципальная доска объявлений и настольный таймер. Literata отвечает за задачу, IBM Plex Mono — за цифры и длительность. палитра: bone `#F6F1E8`, paper `#FFFAF2`, ink `#1D1D1B`, traffic red `#D94735`, signal blue `#325B7C`.

одна очевидная прямоугольная кнопка, спокойные вторичные действия и настройки, которые раскрываются по запросу. без градиентов, glassmorphism, декоративных bubble-элементов, неона, endless scroll, streak-механик и SaaS-дашборда.
