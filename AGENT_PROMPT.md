# boring button: контекст для следующей правки

статический офлайн-инструмент для короткого перерыва за компьютером. когда рука тянется к ленте, человек выбирает настроение и время, нажимает кнопку и получает занятие на 10–120 секунд. после «сделано» пауза завершается.

## интерфейс

уточнение пользователя 14 октября 2026: светлый нейтральный фон, синяя круглая кнопка и функциональный таймер. жёлтый фон, декоративные надзаголовки, звёздочки, стрелки, круговые надписи и текстуры убраны. палитра: фон `#f7f8fa`, поверхность `#eef0f3`, синий `#243de8`, тёмный `#20242b`. literata — для пояснений, ibm plex mono — для подписей и цифр. шрифты локальные.

на сайте, телефоне и в popup — одна рабочая поверхность, без большого лозунга. выбор режима — обычный select, время — три кнопки. во время занятия выбор свёрнут и настраивает следующую паузу. завершение заменяет занятие и таймер. библиотеки и собственные задачи расположены ниже строками. popup использует компактную композицию, в которой основная кнопка видна без прокрутки. анимации короткие, `prefers-reduced-motion` их отключает. не добавляй бесконечную ленту, серии достижений и давление счётчиками.

## поведение

- 60 встроенных занятий из `tasks.json`, разделы: движение, внимание, порядок, наблюдение, мини-игра;
- случайный выбор по настроению и лимиту времени 30/60/120 секунд;
- избранное: случайный выбор учитывает время, явный запуск из списка использует указанное время конкретного занятия;
- свои задачи, импорт и экспорт json/csv;
- таймер с паузой, перезапуском и восстановлением после закрытия;
- локальное хранение собственных задач, избранного, настроек, счётчиков и сессии.

## ограничения и проверка

не добавляй сеть, аналитику, аккаунты, ai и разрешения расширения без отдельного решения. файлы обрабатываются в браузере. manifest v3 не содержит permissions, host permissions или content scripts.

корень проекта — источник интерфейса. после изменения задач запускай `node scripts/sync-tasks.js`, после изменения html/css/ядра/приложения — `node scripts/sync-ui.js`. не правь производные файлы расширения вручную.

проверки: `node --test tests/*.test.js`, синтаксис javascript и браузерные сценарии `scripts/verify-workspace.cjs`, `scripts/verify-browser.cjs`, `scripts/verify-selection.cjs` и `scripts/verify-motion.cjs` с установленным playwright. проверяй клавиатуру, фокус, reduced-motion, пустые состояния, 320–1440 px и реальное закрытие popup. при изменении внешнего вида обновляй скриншоты через `scripts/capture-screenshots.cjs`.
