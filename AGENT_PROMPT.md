# boring button: контекст для следующей правки

статический офлайн-инструмент для короткого перерыва за компьютером. когда рука тянется к ленте, человек выбирает настроение и время, нажимает кнопку и получает занятие на 10–120 секунд. после «сделано» пауза завершается.

## интерфейс

пользователь выбрал яркий дизайнерский эксперимент 14 октября 2026: жёлтая панель, синяя круглая кнопка, крупная типографика, текстура точек и графический таймер. палитра: жёлтый `#f5e642`, синий `#243de8`, тёмный `#20231c`, бумага `#f9f8f1`. literata — для пояснений, ibm plex mono — для подписей и цифр. шрифты локальные.

на сайте — две колонки; на телефоне — одна. popup использует компактную композицию, в которой основная кнопка видна без прокрутки. анимации короткие, `prefers-reduced-motion` их отключает. не добавляй бесконечную ленту, серии достижений и давление счётчиками.

## поведение

- 60 встроенных занятий из `tasks.json`, разделы: движение, внимание, порядок, наблюдение, мини-игра;
- случайный выбор по настроению и лимиту времени 30/60/120 секунд;
- избранное: случайный выбор учитывает время, явный запуск из списка использует указанное время конкретного занятия;
- свои задачи, импорт и экспорт json/csv;
- таймер с паузой, перезапуском и восстановлением после закрытия;
- локальное хранение собственных задач, избранного, настроек, счётчиков и сессии.

## ограничения и проверка

не добавляй сеть, аналитику, аккаунты, ai и разрешения расширения без отдельного решения. файлы обрабатываются в браузере. manifest v3 не содержит permissions, host permissions или content scripts.

корень проекта — источник интерфейса. после изменения задач запускай `node scripts/sync-tasks.js`, после изменения html/css/ядра/приложения — `node scripts/sync-ui.js`. не правь производные файлы расширения вручную.

проверки: `node --test tests/*.test.js`, синтаксис javascript и `scripts/verify-browser.cjs` с установленным playwright. проверяй клавиатуру, фокус, reduced-motion, пустые состояния, 320–1440 px и реальное закрытие popup. при изменении внешнего вида обновляй скриншоты через `scripts/capture-screenshots.cjs`.
