# публикация на github pages

корень репозитория содержит готовый статический сайт. точка входа `index.html`, сборка не нужна. демо проекта: [chebaturkin.github.io/boring-button](https://chebaturkin.github.io/boring-button/).

## настройки

в этом репозитории pages уже настроен на ветку `main` и папку `/ (root)`. изменения сайта появляются после обновления `main` и успешного развёртывания pages.

для собственной копии:

1. загрузите проект в репозиторий github;
2. откройте **Settings → Pages**;
3. выберите **Deploy from a branch**;
4. укажите ветку `main` и папку `/ (root)`;
5. сохраните и дождитесь адреса сайта.

`.nojekyll` в корне позволяет отдавать файлы без обработки jekyll. пути к ресурсам относительные, поэтому сайт работает и в подпапке репозитория.

## перед публикацией

```bash
node scripts/sync-tasks.js
node scripts/sync-ui.js
node --test tests/*.test.js
node --check app.js
node --check extension/popup.js
python3 -m http.server 8000 --bind 127.0.0.1
```

откройте [локальный сайт](http://127.0.0.1:8000). проверьте выбор по настроению и времени, пустое избранное, старт, таймер, завершение, свои задачи и ширину 320 пикселей. если менялся дизайн, обновите скриншоты в `docs/screenshots/` скриптом `scripts/capture-screenshots.cjs` с установленным playwright.

pages обслуживает сайт, но не синхронизирует пользовательские данные. после первой загрузки интерфейс не обращается к сети; для полностью локального запуска откройте `index.html` из папки или установи расширение.
