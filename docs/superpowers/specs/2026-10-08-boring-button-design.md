# Boring Button — дизайн MVP

## Цель
Офлайн-антискролл с одной понятной кнопкой: пользователь получает одну короткую микрозадачу из локального набора, отмечает результат и может взять следующую.

## Визуальная система
- Тон: тихая локальная утилита, собранная вокруг одного действия и одного короткого задания.
- Палитра: bone `#F6F1E8`, ink `#1D1D1B`, traffic red `#BD3B2F` (edge `#963027`), signal blue `#325B7C`, muted `#8C877E`.
- Типографика: Literata для задания, IBM Plex Mono для счётчиков и служебных подписей, локальные fallback.
- Геометрия: bone-фон, тёплая карточка с мягким радиусом, круглый таймер в signal blue, красная кнопка и текстовые вторичные действия, без карточной сетки и декоративных бейджей.
- Анимация: короткая смена текста, отключается через `prefers-reduced-motion`.

## Сценарий
1. На старте видна кнопка «Дай задачу», короткая бытовая фраза и круглый таймер с понятным состоянием.
2. Нажатие выдаёт случайное локальное задание и запускает таймер.
3. Пользователь может поставить таймер на паузу или начать его заново, затем нажимает «Сделано», «Пропустить» или «Другая».
4. В разделе настроек можно добавить своё задание, удалить отдельную свою задачу, импортировать JSON/CSV и экспортировать текущий список.
5. Локально хранятся только пользовательские задания, отметки выполнено/пропущено и дата последнего действия.

## Архитектура
Статический сайт без сборки: `index.html`, `styles.css`, `app.js`, `tasks.json`. Расширение Manifest V3 повторно использует те же ассеты через `extension/` и открывает popup. Данные обмениваются только с `localStorage`; сеть и host permissions не нужны.

## Доступность и ошибки
Все действия доступны с клавиатуры, фокус заметен, кнопки имеют понятные `aria-label`, активное задание объявляется через `aria-live`. Невалидный импорт показывает короткую ошибку рядом с полем и не стирает текущий список. Пустой пользовательский список возвращается к локальному набору.
