# boring button

маленькая офлайн-пауза вместо бесконечного скролла. одна кнопка выдаёт дело, наблюдение или мини-игру на 10–120 секунд — и потом можно спокойно вернуться к своим делам.

## как это работает

1. нажми **«дай задачу»**.
2. сделай то, что написано. таймер запустится сам.
3. отметь **«сделано»**, **«пропустить»** или возьми **«ещё одну»**.
4. если закроешь popup, задача и таймер сохранятся на этом устройстве и вернутся при следующем открытии.

соседняя задача не повторяется, пока остаются другие варианты. счётчик «сегодня» сбрасывается после местной полуночи. аккаунтов, сервера, AI, рекламы и аналитики здесь нет.

## сайт для GitHub Pages

корень проекта уже является статическим сайтом: `index.html` лежит на верхнем уровне и не требует сборки. включи Pages для ветки `main` и папки `/ (root)` — подробные шаги собраны в [`docs/github-pages.md`](docs/github-pages.md).

## что внутри

- `index.html`, `styles.css`, `core.js`, `app.js`, `tasks.js` — сайт для GitHub Pages.
- `tasks.json` — исходный список из 40 задач. после правки запусти `node scripts/sync-tasks.js`, чтобы обновить копии для сайта и расширения.
- `extension/` — popup для расширения Manifest V3.
- `tests/core.test.js` — тесты чистого ядра на Node.js.
- `assets/fonts/` — Literata для текста задачи и IBM Plex Mono для таймера и счётчиков.

сборщик и зависимости не нужны.

## локальный запуск

```bash
python3 -m http.server 8000
```

открой <http://127.0.0.1:8000>. страницу можно открыть и через `file://`: базовые задачи уже встроены в `tasks.js`.

## расширение

1. открой `chrome://extensions` или `edge://extensions`.
2. включи **Developer mode**.
3. выбери **Load unpacked** и укажи папку `extension/`.
4. закрепи расширение на панели браузера.

в Firefox временная установка доступна через `about:debugging → This Firefox → Load Temporary Add-on`.

в `extension/manifest.json` нет `permissions`, `host_permissions` и content scripts. расширение не читает вкладки, историю, cookies или содержимое страниц и не делает сетевых запросов.

## данные и приватность

в браузере остаются только свои задачи, счётчики выполненных и пропущенных задач и активная сессия. данные хранятся в `localStorage` текущего сайта или popup и не синхронизируются между устройствами. импорт и экспорт происходят в браузере; файл не отправляется на сервер.

- **«изменить»** правит свою задачу на месте;
- **«удалить свои задачи»** очищает пользовательский список;
- **«сбросить статистику»** обнуляет счётчики.

импорт ограничен 1 МБ и 200 пользовательскими задачами. пустые, повреждённые и повторяющиеся строки не добавляются.

## формат импорта

JSON может быть массивом задач или объектом с полем `tasks`:

```json
{
  "version": 2,
  "tasks": [
    {
      "id": "custom-window-01",
      "category": "наблюдение",
      "title": "пять круглых предметов",
      "prompt": "найди глазами пять круглых предметов вокруг себя.",
      "durationSec": 30
    }
  ]
}
```

CSV использует заголовки `id,category,title,prompt,durationSec`. поля с запятыми и переносами строк заключай в двойные кавычки. `title` и `prompt` обязательны, длительность — целое число от 10 до 120 секунд.

## клавиатура и доступность

- `Enter` — начать или взять ещё одну задачу;
- `D` — отметить текущую задачу сделанной;
- `S` или `Escape` — пропустить;
- `N` — взять ещё одну;
- `Space` на сфокусированной кнопке запускает её обычное действие.

горячие клавиши не срабатывают внутри полей и ссылок. фокус виден через `focus-visible`, статусы объявляются через `aria-live`, а `prefers-reduced-motion` отключает лишние переходы.

## проверка

```bash
node --test tests/core.test.js
node --check app.js
node --check extension/popup.js
node scripts/sync-tasks.js
```

для ручной проверки пройди старт, паузу, продолжение, перезапуск, завершение, пропуск, восстановление после перезагрузки и закрытия popup, импорт JSON/CSV и ширины 320/360/740 px. горизонтального скролла быть не должно.
