# boring button

**меньше скролла. больше жизни.**

когда в перерыве между работой или учёбой рука тянется к ленте — нажми кнопку. получишь одно короткое занятие: размяться, заметить что-то вокруг, навести порядок или поиграть. от 10 секунд до двух минут, а потом обратно к своему дню.

**[нажать кнопку →](https://chebaturkin.github.io/boring-button/)** · [установить расширение](#расширение) · [запустить локально](#разработка)

![главный экран boring button: светлая панель выбора и большая синяя кнопка](docs/screenshots/desktop.png)

## кому пригодится

- работаешь за компьютером и хочешь переключиться между двумя делами;
- учишься и нужен короткий перерыв, который не растянется на полчаса;
- замечаешь, что открываешь соцсеть просто потому, что нечем занять минуту;
- хочешь собрать собственный набор небольших занятий.

## что умеет

| | |
| --- | --- |
| **выбор по настроению** | как угодно, размяться, переключиться, порядок, поиграть |
| **выбор по времени** | до 30 секунд, до минуты или до двух минут |
| **60 занятий** | пять разделов; есть короткие варианты в каждом |
| **избранное** | сохрани через ♡, начни из списка или доверь выбор кнопке |
| **свой набор** | скрой неподходящее занятие и верни его, когда захочется |
| **таймер** | пауза, продолжение, перезапуск и восстановление после закрытия |
| **свои задачи** | добавляй, редактируй и переноси через json или csv |
| **конец паузы** | «сделано» завершает занятие и предлагает вернуться к своему дню |
| **локальные счётчики** | сколько пауз было сегодня и за всё время |

в выбранном наборе занятия не повторяются, пока не покажутся все. история сохраняется между открытиями; смена настроения или времени начинает новый круг. если доступно только одно занятие, оно может повторяться. уже запущенный таймер от смены фильтра не сбрасывается. в пустом наборе интерфейс предлагает добавить времени, сменить раздел или вернуть скрытые занятия.

## как выглядит

одна рабочая поверхность для выбора, занятия и завершения. в начале видны режим, время и синяя объёмная кнопка. во время занятия выбор свёрнут: его можно открыть и настроить следующую паузу, сохранив текущий таймер. после «сделано» появляются итог и следующие действия. поверхность кнопки продавливается, занятие появляется коротким движением. области нажатия остаются на месте. при настройке «уменьшить движение» анимации отключаются, в том числе уже запущенные.

## попробовать

1. выбери, как хочется отвлечься, и сколько есть времени. можно оставить «как угодно» и «до 2 мин»;
2. нажми **«дай занятие»**. таймер начнётся сам;
3. сделай то, что написано. если не подходит — **«другое»** или **«закончить паузу»**;
4. нажми **«сделано»**. пауза закончилась; можно возвращаться к своим делам.

♡ сохраняет занятие в избранное. раздел **«сохранённые занятия»** позволяет начать конкретное занятие; выбор **«из сохранённых»** на первом экране выдаёт случайное из сохранённых с учётом времени.

если занятие совсем не подходит, нажми **«больше не предлагать»**. оно перестанет попадаться и исчезнет из списка любимых, но отметка избранного сохранится. вернуть его можно через **«мой набор → скрытые занятия → вернуть»**. скрытие не считается выполнением или пропуском.

## расширение

версия для chrome и edge — обычное распакованное расширение manifest v3.

1. [скачай репозиторий](https://github.com/chebaturkin/boring-button/archive/refs/heads/main.zip) и распакуй;
2. открой `chrome://extensions` или `edge://extensions`;
3. включи **Developer mode**;
4. нажми **Load unpacked** и выбери папку `extension/` внутри распакованного проекта;
5. закрепи boring button на панели браузера.

при закрытии popup занятие сохраняется. запущенный таймер продолжает идти по времени устройства, а поставленный на паузу остаётся на паузе.

подробности — в [инструкции расширения](extension/README.md). в каталоге браузера расширение пока не опубликовано.

## данные остаются у тебя

сайт загружает только свои файлы. после загрузки занятия, шрифты, таймер и работа с файлами не обращаются к сети. страницу также можно открыть прямо из папки через `file://`. расширение целиком работает офлайн.

аккаунтов, рекламы, аналитики и ai здесь нет. в manifest отсутствуют `permissions`, `host_permissions` и content scripts: расширение не читает вкладки, историю или содержимое страниц.

в `localStorage` хранятся свои задачи, избранное, скрытые занятия, история текущего круга, настройки выбора, счётчики и активное занятие. сайт и расширение хранят данные отдельно; между устройствами они не синхронизируются. файлы импорта и экспорта обрабатываются в браузере. экспорт переносит только собственные задачи. удаление своих задач и сброс статистики — отдельные действия с подтверждением.

## клавиатура

| клавиша | действие |
| --- | --- |
| `Enter` | начать занятие или получить следующее |
| `D` | отметить сделанное |
| `S` / `Escape` | пропустить; `Escape` также закрывает настройки |
| `N` | другое занятие |
| `Tab` / `Shift+Tab` | перейти между элементами |
| `Space` | нажать выбранную кнопку |

в полях, редактируемом тексте, ссылках и раскрывающихся заголовках горячие клавиши не срабатывают. сочетания с ctrl/cmd/alt, удержание клавиши и композиция ввода не меняют занятие. фокус виден, статусы объявляются через `aria-live`, уменьшение движения и системные контрастные цвета поддерживаются.

## свои задачи и импорт

добавляй свои занятия в разделе **«мои задачи»**. название — до 80 символов, инструкция — до 240, время — от 10 до 120 секунд. лимит: 200 собственных задач и файл до 1 мб. повреждённые строки и дубликаты не добавляются; целочисленное время вне диапазона приводится к его границам.

json принимает массив или объект с полем `tasks`:

```json
{
  "tasks": [
    {
      "id": "custom-window-01",
      "category": "наблюдение",
      "title": "пять круглых предметов",
      "prompt": "найди глазами пять круглых предметов вокруг себя.",
      "durationSec": 30
    }
  ]
}
```

csv использует заголовки `id,category,title,prompt,durationSec`. значения с запятой или переносом строки заключай в двойные кавычки. экспорт скачивает собственные задачи; избранное и статистика в этот файл не входят.

## разработка

статический html, css и javascript. сервер, сборщик и зависимости для работы приложения не нужны.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

открой [локальный сайт](http://127.0.0.1:8000). развёртывание на github pages — [в отдельной инструкции](docs/github-pages.md).

| файл | за что отвечает |
| --- | --- |
| `index.html`, `styles.css`, `app.js` | общий интерфейс и сценарии |
| `core.js` | нормализация, выбор задач, таймер и состояние |
| `tasks.json` | источник встроенных задач |
| `scripts/sync-tasks.js` | копии задач для сайта и расширения |
| `scripts/sync-ui.js` | копия общего интерфейса для popup |
| `extension/` | готовое распакованное расширение |
| `assets/fonts/` | локальные literata и ibm plex mono с лицензиями |
| `docs/screenshots/` | реальные экраны для readme |

после изменения задач или интерфейса:

```bash
node scripts/sync-tasks.js
node scripts/sync-ui.js
node --test tests/*.test.js
node --check app.js
node --check extension/popup.js
```

если в окружении установлен playwright, можно запустить полный сценарий браузерной проверки и заново снять скриншоты:

```bash
BORING_BUTTON_URL=http://127.0.0.1:8000 node scripts/verify-workspace.cjs
BORING_BUTTON_URL=http://127.0.0.1:8000 node scripts/verify-browser.cjs
BORING_BUTTON_URL=http://127.0.0.1:8000 node scripts/verify-selection.cjs
BORING_BUTTON_URL=http://127.0.0.1:8000 node scripts/verify-motion.cjs
BORING_BUTTON_URL=http://127.0.0.1:8000 node scripts/capture-screenshots.cjs
```

браузерная проверка проходит фильтры, избранное, паузу и восстановление таймера, завершение, клавиатуру, свои задачи, импорт/экспорт и семь ширин от 320 до 1440 пикселей. проверка движения дополнительно проходит быстрые повторы, неподвижность кнопок, фокус и выделение текста, переключение reduced motion, сенсорное управление, 200 своих задач, офлайн и `file://`. отдельно проверь распакованное расширение через `chrome://extensions`: установку и восстановление после закрытия popup.

`verify-workspace.cjs` проверяет три состояния поверхности, видимость кнопки, выбор следующего занятия, восстановление и сохранение фокуса между вкладками. `verify-selection.cjs` проверяет полный круг, скрытие и возврат, пустой набор, состояние между вкладками и защиту горячих клавиш. [исследование аналогов и выбранные улучшения](docs/analogues.md) содержит ссылки на исходные файлы и лицензии.
